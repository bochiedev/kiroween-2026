# Product
PaperFault: Learn by Breaking is a browser-based learning experience for junior developers and instructors. Users see an API -> Queue -> Worker -> Database model, run a simulated order, remove a Database service physically via camera marker or digitally, observe the consequences, restore service, and explore a deterministic event trail. Four fixed cards. One lesson. One polished end-to-end experience. No real payments, external LLM dependency, authentication or backend required.

Primary category: Frankenstein — paper + computer vision + executable distributed-system teaching simulation.
Goal: clear value, memorable demo, excellent execution, credible engineering evidence. Do not claim features before implemented and verified.
